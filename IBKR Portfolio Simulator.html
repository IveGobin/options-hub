Market data
The statement only has closing prices for the day it was generated, and none for underlyings you don't hold. Enter current prices to make the margin estimates accurate. Your entries are saved in this browser. Stock maintenance % is IBKR's requirement for that stock (default 25%; IBKR asks more for volatile names — check it in TWS).
Stocks
Options
Mark = option price used for closing and for the margin estimate (statement close by default; edit it to today's mid price). Margin uses IBKR's Reg T rule for short options: premium + max(20% × underlying − OTM amount, 10% × strike for puts / underlying for calls). Calls covered by 100 shares need no margin. Long options and spreads are margined leg by leg, so spreads may show more margin than IBKR charges.

Stress test
Moves every underlying by the same percentage. Option prices are repriced with Black-Scholes using the implied volatility backed out from each mark, so they're rough. Uses the simulated portfolio unless stated otherwise.
